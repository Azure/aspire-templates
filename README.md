# aspire-templates

Azure-focused templates for Aspire.

## Templates

- [`aspire-azure-starter`](templates/aspire-azure-starter): Blazor frontend and ASP.NET Core API targeting Azure Container Apps, with optional Azure Managed Redis.
- [`aspire-support-desk`](templates/aspire-support-desk): Real-time customer support demo with a public site, an agent console and an ASP.NET Core API, connected through the Azure Web PubSub emulator.
